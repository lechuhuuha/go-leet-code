QA
Why do we need the second loop to fill zeroes? What would the output become after only the first loop for this input?
[]int{0, 1, 0, 3, 12}

we are not swapping zero with actual data. 
We are overwriting the front positions with non-zero values.
After the first loop only:
[1, 3, 12, 3, 12]
The last 3, 12 are old values left behind, so the second loop is needed to clean them:
[1, 3, 12, 0, 0]
